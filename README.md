# MATRYX CHAT — runnable starter

## Requirements
- Node.js 18+ recommended
- A modern browser

## Run
1. Open a terminal in this folder.
2. Run:
   npm install
   npm start
3. Open:
   http://localhost:3000
4. Register two usernames in two browser tabs/devices and chat.

## Included
- Register/login
- Real-time 1-to-1 text chat
- Online/offline presence
- Typing indicator
- Image/video/file upload
- Voice calls
- Video calls using WebRTC
- Local JSON database for easy testing

## Important for real deployment
For internet use, run behind HTTPS. Browsers generally require a secure context for microphone/camera access. A production app should also use a real database, object storage, authentication/session tokens, a TURN server for reliable calls, rate limits, virus/file scanning, and proper access control.
